## 📊 Vendor Performance Analysis  
**Exploratory Data Analysis & Strategic Insights**  
`Python` `Pandas` `Matplotlib` `Seaborn` `SciPy` `SQLite` `Power BI`

- Analyzed **10,692 vendor‑brand transactions** to uncover procurement concentration, bulk‑discount benefits, slow‑moving inventory, and hidden high‑margin opportunities.  
- Applied **hypothesis testing** (two‑sample t‑test) to validate profitability differences between vendor tiers.  
- Delivered a structured report with **six research questions**, statistical evidence, and a prioritised list of business recommendations.

## 🏬 Store Sales Data Warehouse & Analytics  
**Medallion Architecture · SQL Server · PySpark**  
`PySpark` `SQL Server` `Medallion (Bronze/Silver/Gold)` `Star Schema` `Draw.io`

- Built a **modern data warehouse** from raw CSV transactions using **Bronze → Silver → Gold** layers.  
- Implemented **automated data quality checks** (duplicate keys, negative values, date integrity) that stop the pipeline on failure.  
- Designed a **star schema** (`dim_customers`, `dim_products`, `fact_sales`) and pre‑built report views for instant dashboard consumption in Power BI or Tableau.  
- Analytics ready: customer segmentation, product performance, moving averages, and geographic distribution.
